Language Translation Tool

About the Project

This is a simple Language Translation Tool developed using HTML, CSS, and JavaScript.

It helps users translate text between different languages.

Technologies Used

- HTML
- CSS
- JavaScript

Project Files

- index.html – Creates the webpage.
- style.css – Designs the webpage.
- script.js – Handles the functionality.

How to Run

1. Download the project files.
2. Open Index.html in a web browser.
3. Use the translation tool.
